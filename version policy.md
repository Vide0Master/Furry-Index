# Version policy for Furry Index

Each version number consists of 4 parts.
In A.B.C-D there is:
- **A** *number* - major version.
- **B** *number* - minor version.
- **C** *number* - patch version.
- **D** *letter* - fix version. 

> [!IMPORTANT]
> Fix versions made only when fixes applied to code, after something was planned, deployed, failed when testing in **almost real scenario**, and got a fix. This is when fix version applies, not patch.

> [!NOTE]
> There is small difference between major and minor versions. Major version is updated when some development milestone achieved, some **BIG** milestone. Minor can be updated on big changes.
